## 세션 폴더 구조

한 세션 = 폴더 하나. 폴더 이름은 `날짜_실험ID_속도_회차` (예: `20261012_S1_normal_03`).

```
data/
  20261012_S1_normal_03/
    <센서별 CSV>
```
