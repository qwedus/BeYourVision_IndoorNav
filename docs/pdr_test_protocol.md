# PDR 테스트 프로토콜 (1단계: 기초 데이터 수집)

준비물: 줄자, 마스킹 테이프, 휴대용 카운터, 조끼.

## 1. 측정 장소 준비

- 사람이 적은 직선 복도와, 한 바퀴 돌 수 있는 복도 경로를 고른다.
- 바닥에 테이프로 출발점과 체크포인트를 표시한다.
- 줄자로 구간 거리를 두 번 재서 평균을 기록한다.
- 회전 실험용으로 바닥에 테이프 십자(+)를 표시한다. 바닥 타일 줄에 맞추면 각도가 정확하다.

## 2. 모든 실험 공통 루틴

1. 조끼 장착, 앱 기록 시작
2. 출발점에서 5초 정지 (데이터 시작 기준)
3. 체크포인트 도착 시 3초 정지 + Annotation 버튼
4. 종료 지점에서 5초 정지 후 기록 종료
5. 바로 메타데이터 기록: 실험 ID, 시각, 속도, 직접 센 걸음 수, 특이사항 (`docs/sessions.csv`)

## 3. 실험 목록

| ID | 실험 | 방법 | 반복 |
|----|------|------|------|
| S1 | 직선 보행 | 25m 직선을 느림/보통/빠름으로. 카운터로 걸음 수 세기 | 속도별 4회 |
| S2 | 직선 왕복 | S1 끝에서 180° 돌아 출발점 복귀 | 2회 |
| R1 | 제자리 회전 | 십자 위에서 90° → 180° → 270° → 360°, 각 방향에서 3초 정지 | 좌·우 회전 각 2회 |
| T1 | L자 경로 | 직선 → 90° 회전 → 직선 | 4회 |
| T2 | L자 왕복 | T1 도착점에서 180° 돌아 출발점 복귀 | 2회 |
| L1 | 폐루프 | 복도 한 바퀴 돌아 출발점·출발 방향으로 복귀 | 4회 |
| Z1 | 정지 | 1분간 움직이지 않기 | 2회 |
| E1 | 엘리베이터 | 1개 층 올라갔다 내려오기, 탑승·하차 시 Annotation | 2회 |

## 4. 파일 관리

- 파일 이름 규칙: `날짜_실험ID_속도_회차` (예: `20261012_S1_normal_03`)
  - 속도: `slow` / `normal` / `fast`, 속도 구분이 없는 실험은 `na`
- 원본은 공유 저장소(Google Drive 등)에 올리고, 레포에는 위치만 기록한다 (`sessions.csv`의 `storage_path`).
- 각 실험의 홀수 회차는 튜닝용(`tune`), 짝수 회차는 평가용(`eval`)으로 미리 정해둔다.

## 5. 수집 후 바로 확인 (그날 안에)

- CSV를 노트북에서 불러와 그래프를 그린다.
- 걸음 물결이 보이는지, 정지 구간이 평평한지, Annotation 시각이 찍혔는지 확인한다.
- 이상한 세션은 메타데이터의 `flag`에 표시하고, 필요하면 다시 측정한다.

## sessions.csv 컬럼

| 컬럼 | 설명 |
|------|------|
| session_id | 파일 이름 규칙과 동일 (예: `20261012_S1_normal_03`) |
| date, start_time | 측정 날짜(YYYYMMDD), 시작 시각(HH:MM) |
| experiment_id | S1 / S2 / R1 / T1 / T2 / L1 / Z1 / E1 (경로별 정답은 `routes.csv`) |
| speed | slow / normal / fast / na |
| run | 회차 번호 |
| split | tune(홀수 회차) / eval(짝수 회차) |
| operator | 측정자 |
| phone_model, os, app_version | 측정 기기, OS 버전, Sensor Logger 버전 |
| location | 측정 장소 |
| distance_m | 줄자로 잰 구간 거리 (두 번 측정 평균) |
| manual_step_count | 카운터로 직접 센 걸음 수 |
| storage_path | 공유 저장소 내 원본 위치 |
| flag | 정상이면 비움, 이상 세션이면 `bad` / `redo` |
| notes | 특이사항 |

## 미정 사항 (1단계 시작 전 결정)

- [ ] Annotation 입력 방법 (폰 직접 터치 시 충격이 기록되는 문제)
- [ ] 폰 축 → 몸 축 매핑 (장착 방향 그림)
- [ ] L1/T1 경로의 구간 길이·코너 좌표 기록 방식
- [ ] 합격 기준 (걸음 수·거리·heading·폐루프 오차 목표치)
