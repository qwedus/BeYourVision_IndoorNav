# vision-ocr 브랜치 — 랜드마크 인식 OCR 보강 (김윤재)

YOLO가 찾은 표지판을 **글자(OCR)로 한 번 더 확인**하는 부분의 결과와 설정을 모아 두는 브랜치. 아이폰 **Apple Vision OCR** 시험 결과와 최종 판정 설정(0.2.9)이 들어 있다. **OCR 보강은 11-08에 마무리**(아래 결론).

- `main`에서 갈라짐. **기존 파일은 고치지 않고** 새 문서·설정만 더함
- 비전 관측을 PDR·PF에 붙이는 작업은 `vision-integration` 브랜치(김정환). 이 브랜치와 폴더가 겹치지 않음
- 결과 정리: [아이폰OCR_결과.md](아이폰OCR_결과.md), 조정 과정 한 표: [OCR조정과정.md](OCR조정과정.md)

## 처리 흐름 (아이폰 시험 앱 기준)

```
카메라 영상(30/60 fps)
 → 0.2초마다 가장 덜 흔들린 1장 (초당 5장)
 → YOLO 검출 (동춘 추가학습 모델)
 → ① 종류별 문턱값 → ② 크기 상한(주변지역 안내도) → ③ 시간 필터(최근 5장 중 3번, 같은 판 잇기)
 → ④ OCR: 판마다 한 번, 박스 안만 Apple Vision "정확"으로 읽음
          작은 판은 높이 120px까지 키워 읽고, 확인 안 되면 2배·흑백 대비로 한 번 더
          못 읽으면 0.5초 뒤 다시 (최대 3번)
 → ⑤ 판정: 확인 / 종류 바로잡음 / 버림(광고 등) / 못 읽음
```

- OCR 결과를 기다리는 동안 판은 "읽는 중"으로 **남겨 둔다**(버리지 않음).
- 못 읽은 판도 버리지 않고 "못 읽음" 상태로 남긴다. 위치추정에서 낮게 믿는 것을 제안.

## 설정 파일 읽는 법 (`configs/ocr_filter_app_v0.2.9.json`)

| 묶음 | 내용 |
|---|---|
| `label_map`, `drop_labels`, `detectors` | YOLO 종류 → 지도 종류, 버릴 종류, 종류별 검출 문턱값. CV 모듈 기본 설정과 키가 같음 |
| `size_limits` | 종류별 박스 높이 / 화면 높이 상한. **주변지역 안내도 0.7 켬**(벽 오검출 제거, CV 모듈 기본값에는 아직 없음) |
| `time_filter` | 최근 5장 중 3번, 같은 판 잇기(겹침 0.3) |
| `ocr` | OCR 대상 종류, 다시 읽기, 키우기, 판정 규칙, 종류별 글자(`keywords`), 역 이름(`stations`), 판정 코드 보강(`code_rules`) |
| `ocr.keywords.monitor` | 11-04 넓힘: "이번열차"·"This train"과 비슷하면 인정, 시각(20:49) 모양 인정 |
| `ocr.meaningful_conf` | 11-05 0.5 → 0.6: 어느 표지판과도 안 맞는 글자를 광고로 버리는 신뢰도. Apple Vision 정확 모드 신뢰도는 0.3·0.5·1.0 식이라 1.0일 때만 버림("박촌 행"을 "보행 6 %"로 잘못 읽은 진짜 모니터를 버리던 것) |
| `ocr.vision`, `ocr.rotate_retry` | 글자 사전·돌려 읽기. 시험했지만 효과 없음 → 사전은 켜 둠(해 없음), 돌려 읽기는 끔 |

`_`로 시작하는 키는 설명용 메모.

## 판정 상태 이름

| 아이폰 앱 | 뜻 | `vision-integration` 결정 파일의 `text_status` |
|---|---|---|
| `confirmed` | 그 종류 글자를 읽음 | `confirmed` |
| `other_text` (다른 종류 글자) | 다른 표지판 글자 → 종류 바로잡음 | `mismatch` (decision `relabel`) |
| `other_text` (광고 등) | 어느 표지판과도 안 맞는 글자 → 버림 | `mismatch` (decision `reject`) |
| `unreadable`, `no_text` | 글자를 못 읽음 / 글자 영역을 못 찾음 | `unread` |
| `skip` | 글자로 확인하지 않는 종류(화장실·발권기 등) | `skipped` |

## 결론 (11-08 마무리)

1. **판정은 0.2.9로 확정.** 진짜 판을 거의 버리지 않으면서(2차 답사 녹화 5개 관측 버림 200 → 24, 24개 중 4개는 화장실 방향 안내판을 일부러 버린 것), 표지판과 전혀 다른 글자의 광고는 그대로 버린다.
2. **위치 정확도는 OCR로 오르지 않았다.** 2차 답사 녹화 8개로 위치 추정을 재생해 보니 OCR을 켜도 끈 것과 0.05~0.1 m 안팎 차이. 버림·바로잡기·점수 가중치 어느 방식으로 넣어도 같았다.

| OCR 조건 (8개 녹화 평균) | 위치 오차 중앙 / 90% (m) |
|---|---|
| 끔 | 1.23 / 2.92 |
| 앱 그대로 (현장 판정) | 1.19 / 2.80 |
| 0.2.9 | 1.22 / 3.03 |
| 0.2.9 + 확인 더 믿기 + 못 읽음 1/4만 | 1.18 / 2.89 |

3. **OCR은 안전장치로 둔다.** 위치를 해치지 않고, 광고가 바뀌어 YOLO가 처음 보는 광고를 표지판으로 착각할 때 글자로 막는 역할. 위치 추정 기본값은 OCR 끔 그대로 둬도 되고, 켠다면 0.2.9.

## 알게 된 것

- 위치 추정에는 "진짜 판인가"보다 **"지도에 있는 그 판과 같은 물체인가"**가 중요하다. 천장의 "← 화장실" 방향 안내판을 화장실 판으로 바로잡자 지도의 화장실 입구 판과 맞춰져 위치가 틀어짐 → 화장실 글자는 바로잡지 않고 버리도록 바꿈.
- 벽에 세로로 붙은 출구 번호 판("5 ↖", "6 ↗") 관측을 빼면 이마트 쪽 녹화 90% 오차가 6.0 → 3.9 m로 줄었다. 진짜 판인데 빼서 좋아졌으므로 **지도의 이 판 위치·방향 확인이 필요**(추정).
- OCR은 "글자 없음"과 "흐려서 못 읽음"을 구분하지 못한다. 벽·유리창·꺼진 화면 같은 남은 오검출(못 읽음의 약 20%)은 OCR로 거르지 못한다.
