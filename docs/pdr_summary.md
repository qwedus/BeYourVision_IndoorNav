# PDR·PF 개발 요약 (시작 ~ 2026-10-30)

EXIT 프로젝트에서 PDR(보행자 추측항법)과 파티클 필터(PF)를 처음부터 지금까지 어떻게 만들었는지 한 장으로 정리한 문서다.
상세 근거는 [`pdr_improvement_log.md`](pdr_improvement_log.md), PDR 튜닝 표는 [`tuning_log.md`](tuning_log.md), PF 튜닝은 [`pf_tuning_log.md`](pf_tuning_log.md), 구조는 [`pdr_algorithm.md`](pdr_algorithm.md)에 있다.

> **2026-10-29 수치 정정**: 집 복도를 실측해 지도(`maps/home_loop`)를 만들면서 정답 거리가 바뀌었다 (직선 17.4 → **16.8 m**, 폐루프 69.6 → **72.07 / 72.95 m**). 예전 정답은 PDR 오차(직선은 길게, 꺾는 경로는 짧게)와 반대 방향으로 틀려 있어 오차를 가리고 있었다. 이전 문서의 "거리 오차 5.9%"는 옛 정답 기준이다.

---

## 1. 목표와 조건

- **역할:** 비전 맵매칭이 위치를 확정하는 사이를 PDR + PF로 이어 준다 (카메라가 가려져도 위치 유지).
- **기기·장착:** iPhone 15 Pro, 조끼 가슴에 **가로 장착** (왼쪽으로 90° 돌린 방향).
- **센서:** 가속도, 중력, 자이로 (100 Hz, Sensor Logger로 기록). **자력계와 iPhone yaw는 쓰지 않는다** (실내에서 틀어짐).
- **진행 방식:** Sensor Logger 기록 → Python 오프라인 분석 → 정답(직접 센 걸음 수, 실측 지도 거리, 모서리 시각)과 비교하며 튜닝.

## 2. 구조 (확정)

### PDR

| 단계 | 방법 | 파일 |
|---|---|---|
| 전처리 | 중력 방향 수직 가속도 → 저역통과 3 Hz | `preprocess.py` |
| 걸음 검출 | 수직 가속도 봉우리 (높이 0.15, 돌출 0.5, 최소 간격 0.5초) | `step_detect.py` |
| 보폭 | Weinberg `L = K·(a_max − a_min)^0.55`, K = 0.38 | `step_length.py` |
| 제자리 움직임 | 연속 4걸음 미만 묶음(3초 넘게 쉬면 끊음)은 보폭 0 | `step_length.bout_mask` |
| 헤딩 | 자이로 수직축 적분, 걸음 구간 평균 | `heading.py` |
| 위치 | `x += L·cos(h)`, `y += L·sin(h)` | `pipeline.py` |
| 앱용 필터 | 0.5초 지연 방식 (최근 3초를 앞뒤로 필터, 0.5초 전까지 확정) | `preprocess.delayed_filtfilt` |

실행 설정: `configs/pdr_tuned_v4.toml`

### PF (서버용, `indoornav/pf/`)

| 항목 | 방법 |
|---|---|
| 상태 | 파티클 500개 × (x, y, 진행 방향, 보폭 배율 k) |
| 입력 | 걸음마다 PDR의 (보폭, 헤딩 변화, 이동 여부) — 앱 → 서버 메시지와 같은 형식 |
| 지도 | 벽 선분. 이동 선분이 벽을 지나면 그 파티클 제거 → 즉시 리샘플 |
| 보폭 0 걸음 | PDR이 제자리 움직임으로 본 걸음은 "모름"으로 처리 (70% 파티클만 0.1~0.4 m 이동) → 극단적으로 느린 걸음에서도 과신하지 않음 |
| 관측 | 위치 관측(가우시안 + 이상치 바닥값). 비전 방위각·앙각 관측은 다음 단계 |
| 출력 | 위치, 95% 불확실 반경, k, `pdr_suspect`(최근 10걸음 중 절반 이상이 보폭 0 → 앱 "위치 불확실" 안내) |

실행 설정: `configs/pf_home_v3.toml`

## 5. 확정 / 미확정

**확정 (한 사람, 오피스텔 복도, 가슴 가로 장착 조건)**
- PDR 구조 전체, 헤딩 방식, 걸음 검출, 보폭 모델(Weinberg, 지수 0.55), 정지·제자리 처리, 앱용 필터
- PF 구조, 보폭 배율 변화 `sigma_k = 0.02`, 보폭 0 걸음 처리, 파티클 500개 이상

**조건부 (숫자만 다시 맞추면 됨)**
- 걸음 검출 파라미터, 묶음 규칙 → 다른 사람 데이터로 재튜닝 (`scripts/tune_pdr.py`)
- PF 잡음 값(`sigma_len`, `sigma_h0`, `sigma_h1`) → 결과에 둔감, 역에서 확인

**미확정**
- 날마다·세션 안에서 바뀌는 보폭 → PDR이 아니라 PF의 k와 랜드마크 관측으로 보정하는 구조로 결정
- 넓은 공간(대합실)에서의 PF 성능 — 집 복도는 벽 도움이 커서 유리했음
- 비전 관측 관련 값 (방위각·앙각 오차, 오인식 비율) — 비전 결과 필요
- 0.1 m/s 미만 걸음, 계단·엘리베이터(기압 층 판별 미구현), iOS 이식
